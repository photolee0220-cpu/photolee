1접속과 로그인

주소로 들어가 개별로 받은 아이디와 임시 비밀번호로 로그인합니다.

  1. 휴대폰이나 컴퓨터에서 photolee0220-cpu.github.io/photolee 로 접속합니다. (위 QR 코드를 찍어도 됩니다)
  2. 관리자에게 받은 아이디와 임시 비밀번호를 넣고 로그인을 누릅니다.
  3. 처음 로그인하면 본인이 쓸 새 비밀번호(6자 이상)를 정합니다.
아이디·비밀번호는 다른 사람과 공유하지 마세요. 잊어버리면 관리자에게 초기화를 요청하면 됩니다.

2휴대폰 홈 화면에 추가 (권장)

한 번만 해두면 앱처럼 아이콘을 눌러 바로 열 수 있고, 알림도 받을 수 있습니다.

아이폰 (사파리)

  1. 사파리로 주간보고 주소에 접속
  2. 아래쪽 ⬆︎ 공유 버튼
  3. 홈 화면에 추가 → 추가
  4. 홈 화면의 주간보고 아이콘으로 열기

안드로이드 (크롬·삼성 인터넷)

  1. 크롬으로 주간보고 주소에 접속
  2. 오른쪽 위 ⋮ 메뉴
  3. 홈 화면에 추가 (또는 앱 설치)
  4. 홈 화면의 주간보고 아이콘으로 열기

3보고 쓰기

메뉴 이번 주 작성에서 씁니다. 입력하면 자동으로 저장됩니다. 저장 버튼이 따로 없고, 칸 아래 ✓ 저장됨이 보이면 저장된 것입니다.

현장 보고 부서 (공무·인테리어·CM·견적)

  • 위쪽 현장별 보고 부서 업무보고 두 탭으로 나뉩니다.
  • 처음에는 현장 이름만 보입니다. 이름을 누르면 작성 칸이 열립니다.
  • 우리 부서가 맡은 현장만 쓰면 됩니다. 쓴 현장은 ✓ 표시로 바뀝니다.
  • 현장 칸 아래에서 사진과 파일(PDF·엑셀·한글 등, 1개당 20MB까지)을 붙일 수 있습니다.
  • 현장 전체 보기를 누르면 그 현장에 다른 부서가 쓴 내용도 볼 수 있습니다. (열람 권한이 있는 부서만)

부서 업무보고 · 대주제로 나눠 쓰기

  • 내용이 많으면 + 대주제 추가를 눌러 대제목별로 칸을 나눠 쓸 수 있습니다. (예: 공공입찰 / 민간입찰 / 협조 요청)
  • 칸 오른쪽 화살표로 순서를 바꾸고, 휴지통으로 지울 수 있습니다.
  • 칸이 비어 있으면 지난주 내용 불러오기로 지난주 글을 가져와 고쳐 쓰면 편합니다.
  • 현장 보고를 하지 않는 부서는 이 화면 하나만 쓰면 됩니다.

  • 화요일 0시부터 지난주 보고는 보기만 가능합니다. 고칠 내용이 있으면 관리자에게 요청해 주세요.

5피드백 확인 · 지시 처리

대표님·본부장님이 남긴 피드백과 대표님 지시사항을 꼭 확인해 주세요.

  • 새 피드백이 있으면 화면 위에 "피드백 n건이 확인을 기다립니다"가 뜨고, 해당 현장 옆에 피드백 표시가 붙습니다.
  • 내용을 읽고 ✓ 확인했습니다를 눌러 주세요. 대표님 화면에 확인 여부가 바로 표시됩니다.
  • 필요하면 답글을 달 수 있습니다.
  • 대표님 지시사항 아래 대기 진행 중 완료를 눌러 처리 상태를 표시해 주세요.

6월요일 회의: 내 보고

메뉴 내 보고를 엽니다. 회의 때는 휴대폰이나 태블릿으로 이 화면을 보면서 보고하세요.

  • 이번 주에 쓴 현장별 보고가 차례로 나오고, 맨 아래에 부서 업무보고가 나옵니다.
  • 위쪽 현장 이름 버튼을 누르면 그 현장으로 바로 넘어갑니다.
  • 오른쪽 위 가 가 가로 글자 크기를 키울 수 있습니다.
  • '이번 주 작성' 화면의 보고 화면 버튼으로도 들어갈 수 있습니다.

7알림 받기 (선택)

  1. 화면 위쪽(컴퓨터는 왼쪽 아래)의 🔔 버튼을 누릅니다.
  2. 이 기기에서 알림 켜기 → 브라우저가 물으면 허용.
  3. 시험 알림 보내기로 잘 오는지 확인합니다.
  • 금요일 오후 3시, 토요일 오전 8시 30분: 이번 주 보고를 아직 안 쓴 경우에만 알림
  • 대표님·본부장님이 내 보고에 피드백을 남겼을 때 알림
아이폰은 먼저 2번 '홈 화면에 추가'를 하고, 그 아이콘으로 연 다음 알림을 켜야 합니다. (iOS 16.4 이상)

?자주 묻는 질문

저장 버튼이 없는데 저장이 되나요?
네. 입력하면 몇 초 안에 자동 저장되고 칸 아래 ✓ 저장됨이 표시됩니다. 인터넷이 끊기면 저장 실패가 표시되니 다시 입력해 주세요.
컴퓨터에서 쓰고 휴대폰에서 이어서 써도 되나요?
네. 같은 아이디로 로그인하면 어디서든 같은 내용이 보입니다.
다른 부서 보고도 볼 수 있나요?
기본은 우리 부서 보고만 보입니다. 함께 보는 부서는 관리자가 열람 권한을 설정한 경우에만 '함께 보는 부서' 메뉴에 나옵니다.
실수로 내용을 지웠어요.
칸 아래 수정 기록에서 이전 내용을 보고 다시 붙여 넣을 수 있습니다.
지난주 보고를 고쳐야 해요.
화요일부터는 잠겨 있으니 관리자에게 요청해 주세요.
비밀번호를 잊었어요.
관리자에게 초기화를 요청하면 임시 비밀번호를 다시 받습니다.
