사닥다리 업무보고 시스템 · 처음 한 번만 하면 됩니다

다른 직원에게 보여 주세요.
휴대폰 카메라로 QR을 찍으면 이 안내가 열립니다.

  1. 사파리(Safari)로 접속아래 [업무보고 열기]를 누르거나 QR을 찍으면 사파리가 열립니다. 카카오톡 안의 브라우저에서는 안 되니, 사파리로 열어 주세요.
  2. 아래쪽 공유 버튼 누르기화면 아래 가운데 네모에 화살표가 있는 버튼입니다.
    공유
  3. '홈 화면에 추가' 누르기목록을 아래로 내리면 있습니다. 이름은 그대로 두고 [추가]를 누릅니다.
    홈 화면에 추가
  4. 홈 화면의 '업무보고' 아이콘으로 열기앞으로는 이 아이콘으로 들어갑니다. 사파리로 들어가면 알림이 오지 않습니다.
  5. 로그인 → [알림 켜기] → '허용'로그인하면 알림 안내가 뜹니다. 허용을 꼭 눌러 주세요.

아이폰은 iOS 16.4 이상에서 알림을 받을 수 있습니다. (설정 → 일반 → 정보 → iOS 버전)

  1. 크롬(Chrome)으로 접속아래 [업무보고 열기]를 누르거나 QR을 찍으면 열립니다. 삼성 인터넷이 열리면 크롬으로 열어 주세요.
  2. 로그인 → [알림 켜기] → '허용'로그인하면 알림 안내가 뜹니다. 허용을 누르세요.
  3. 오른쪽 위 ⋮ → '홈 화면에 추가' (또는 '앱 설치')홈 화면에 아이콘이 생겨 앱처럼 쓸 수 있습니다.
    ⋮ → 홈 화면에 추가
  4. (선택) 알림 소리 바꾸기휴대폰 설정 → 애플리케이션 → 업무보고(또는 Chrome) → 알림 → 소리에서 원하는 소리로 바꿀 수 있습니다.

'배터리 최적화'가 켜져 있으면 알림이 늦을 수 있습니다. 설정 → 애플리케이션 → Chrome → 배터리 → '제한 없음'으로 두면 좋습니다.

알림이 잘 오는지 확인

로그인 후 오른쪽 위 종 모양 버튼 → [시험 알림 보내기]를 누르면 바로 알림이 옵니다. 안 오면 관리자에게 알려 주세요.
